# What VHD is

A portable home for an original character (OC) and the assistant that occupies it.

The folder holds the character: identity, voice, memory, knowledge, proven methods and the state of ongoing projects, written as Markdown and JSON on your own disk. Change the model, the app or the machine, and the same character continues where it stopped.

> Your AI. Your home. Your memory.

It ships no model and no inference. You bring the model; the folder holds the character. It ships no account, no server and no database, and no format that needs this tool to read.

The folder belongs to whoever owns it. What goes into it, which model reads it and what it is used for are that owner's decisions. The [license](LICENSE) and [disclaimer](DISCLAIMER.md) mark where our responsibility ends.
