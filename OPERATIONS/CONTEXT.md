# Context discipline

Identify the actual task, then follow root -> relevant branch -> required source. Search filenames, symbols, or scoped indexes before expanding retrieval. Read full required procedures and actual affected source. Recover truncated output.

Use one canonical source for each detailed rule or fact. Other files hold short triggers and links. Reuse complete sources already read in the current chat while unchanged. A tool cache or another chat's receipt is not evidence that this chat read the source.

Several small topic files can keep loading selective. Split a growing topic at meaningful boundaries, preserving decisions, reasons, exceptions, dates, and source links. Do not split an unchanged file merely to produce more files.

Keep startup and handoff small. Summaries locate preserved originals; they do not replace required identity or evidence. Do not read every project or all checkpoint history at startup.

Consider input, output, tool results, retries, and final quality when comparing cost. Label bytes and line counts honestly. Use exposed provider usage for actual claims; unavailable categories stay unknown. Prompt instructions are not hard spending limits.
